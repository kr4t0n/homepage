{{- if .Values.prometheus.url }}

The wall boards read from Prometheus at {{ .Values.prometheus.url }}.
Upstream failures are logged server-side and never reach the browser:

  kubectl logs -n {{ .Release.Namespace }} deploy/{{ include "homepage.fullname" . }} | grep pixels
{{- else }}

Running WITHOUT Prometheus, which is a supported mode: the room renders
normally and the two wall boards stay unlit. Set prometheus.url to light them.
{{- end }}
{{- if .Values.persistence.enabled }}

Media is served from PVC {{ include "homepage.pvcName" . }}, mounted read-only. Until it
holds a track.json and the files it names, the room plays nothing. To change
the song, load the new files with a loader pod (see the chart README) and
write track.json last; the next page load picks it up.
{{- else }}

No media volume, so the room runs in silence. Set persistence.enabled to add one.
{{- end }}
